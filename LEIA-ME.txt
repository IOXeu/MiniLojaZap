MINILOJA RELÂMPAGO — VERSÃO COM SERVIDOR
=========================================
O que esta versão faz
- Cada loja ganha um link fixo: seusite.com/nome-da-loja (com fotos).
- O cliente paga no Mercado Pago e o criador libera sozinho, sem você enviar código.
- O gerador-codigos.html continua funcionando (os códigos antigos e novos são aceitos).

PASSO A PASSO (os nomes dos menus podem variar um pouco)

1) GITHUB
   Crie um repositório (ex.: "miniloja") e envie TUDO desta pasta:
   src/, public/, wrangler.jsonc e este arquivo.
   NÃO envie o arquivo SEGREDO_LIC_PRIVATE_JWK.txt para o GitHub.

2) CLOUDFLARE — criar o armazenamento
   Painel Cloudflare > Storage & Databases > KV > Create.
   Nome: miniloja-lojas. Copie o "ID" do namespace.
   No GitHub, abra wrangler.jsonc e troque COLE_AQUI_O_ID_DO_KV por esse ID.

3) CLOUDFLARE — publicar
   Workers & Pages > Create > Import a repository > escolha o repositório > Deploy.

4) CLOUDFLARE — segredos
   Abra o Worker "miniloja" > Settings > Variables and Secrets > Add (tipo Secret):
   - LIC_PRIVATE_JWK  = todo o texto do arquivo SEGREDO_LIC_PRIVATE_JWK.txt
   - MP_ACCESS_TOKEN  = Access Token de PRODUÇÃO do Mercado Pago
                        (Mercado Pago > Suas integrações > criar aplicação > Credenciais de produção)
   - PRECO (opcional) = valor da licença, só números (padrão 19)

5) TESTE
   Abra o endereço do Worker, clique em "Pagar com Mercado Pago", pague e volte ao app.
   Dica: o valor padrão já é 19. Se quiser testar com outro valor, defina PRECO e depois apague a variável.
   Depois crie uma loja e clique em PUBLICAR: o link fixo aparece.

6) DOMÍNIO PRÓPRIO (opcional)
   Worker > Settings > Domains & Routes > Add custom domain.

OBSERVAÇÕES
- O PIX pode levar alguns instantes: se o app avisar "pagamento ainda não confirmado",
  é só tocar em "Verificar pagamento de novo".
- Se um cliente pagar e não conseguir liberar, gere o código no gerador e envie a ele.
- Guarde o SEGREDO_LIC_PRIVATE_JWK.txt em local seguro. Ele é a chave que cria as licenças.
